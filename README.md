## Media File Monitor Server.
    Серверное приложение на C++ для периодического сканирования директорий и отслеживания мультимедийных файлов (аудио, видео, изображения). Результаты доступны через HTTP API в формате JSON и в реальном времени через Server-Sent Events (SSE).

# Возможности.
- Многопоточное сканирование директорий с использованием собственного пула потоков и потокобезопасной очереди задач

- Классификация файлов по категориям: audio, video, images (на основе расширений)

- HTTP-сервер на базе cpp-httplib, отдающий статические файлы (HTML, CSS, JS)

- SSE-поток для обновления данных в реальном времени без перезагрузки страницы

- Веб-интерфейс с таблицей найденных файлов, обновляемой автоматически

- Настраиваемые параметры запуска: путь для сканирования и интервал обновления

| Метод | Путь             | Тип ответа                | Описание                    |
|-------|------------------|---------------------------|-----------------------------|
| GET   | `/`              | text/html                 | Веб-интерфейс               |
| GET   | `/main.js`       | application/javascript    | Клиентский скрипт           |
| GET   | `/style.css`     | text/css                  | Стили                       |
| GET   | `/media_files`   | text/event-stream         | SSE-поток с JSON-данными    |

# Зависимости.
- CMake(>=3.16), make, g++(C++17).
- nlogmann/json.hpp, httplib.h встроил в проект для удобства сборки.
